A GraphMD “Dataset” is a **repository** of files.

GraphMD defines three first-class semantic object classes in the repository:

* **Record objects and type objects** stored as Markdown files with YAML front matter (§5).
* **Block objects** stored as uninterpreted bytes in the canonical block store (§4, §9).
* **Plugin objects** stored as a plugin manifest plus referenced plugin files (§4.1, §5.1, §9.4).

**Markdown with YAML front matter is the canonical persistence format for types and records**, but a dataset’s canonical interchange format also includes:

* block bytes (by canonical path), and
* plugin bundle files referenced by plugin manifests.

Records are Markdown-canonical; plugins and blocks are repository-canonical semantic objects.

Import/export boundaries are repository snapshots (files), not JSON databases.

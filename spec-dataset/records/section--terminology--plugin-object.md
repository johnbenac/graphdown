A **plugin object** is a first-class semantic dataset object defined by:

* a **plugin manifest file** (PLUG-FR-001 / PLUG-FR-002), and
* a set of **plugin bundle files** referenced by the manifest (PLUG-LAYOUT-002).

A dataset MAY contain zero or more plugin objects.

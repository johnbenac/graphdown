# Dataset module map

This folder contains the canonical dataset domain implementation.

## Key areas

- `model/`: dataset identifiers, snapshot types, and core types.
- `parse/`: parsers for dataset files, front matter, wiki references, and plugin manifests.
- `validate/`: validation rules and error helpers.
- `snapshot/`: hashing and canonicalization logic.
- `graph/`: record link graph building utilities.
- `cid/`: CID encoding/decoding helpers.
